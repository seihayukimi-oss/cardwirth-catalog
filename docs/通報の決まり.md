# 通報の決まり

カタログに載っている作品に問題があると思ったときは、通報のページから管理人に知らせてください。

- 通報のページ：https://seihayukimi-oss.github.io/cardwirth-catalog/report/
- CWカタログからは、作品の画面の「通報する」で、作品IDが入った状態で開きます（`report/?id=e00012`）

作者さんご本人で、掲載をやめてほしいときは、通報ではなく「[登録内容の変更・解除](https://seihayukimi-oss.github.io/cardwirth-catalog/manage/)」の「掲載停止の申請」をお使いください。すぐに非公開になります。

## 理由と、一時保留になる人数

同じ作品に、同じ理由の通報が決まった人数集まると、管理人が確かめるまで**一時保留**になります。一時保留の作品は、CWカタログでは、いつもは表示しません。

| 理由 | 一時保留になる人数 |
|---|---|
| 年齢区分の不備（R18作品が全年齢・R15表記になっている等） | 5人 |
| 無断転載・無断改変・作者様の意向違反 | 20人 |
| 危険なファイル・不適切なコンテンツ | 20人 |
| その他（詳しい内容が必須） | 20人 |
| リンク切れ・配布先の不備 | 保留にしない（管理人に知らせるだけ） |

- 同じ人（同じ IP アドレス）が、同じ作品に同じ理由で何度送っても、1人と数えます
- 1人が1日に送れる通報は30件までです
- 一時保留は、管理人が確かめて、公開に戻すか、ほかの状態にします

## 通報した人の情報

- 通報の内容や、通報した人のことは、ほかの人には公開しません（カタログのリポジトリにも入りません）
- IP アドレスは、そのまま保存しません。重ねて数えないために、**元に戻せない識別子（ハッシュ値）**にして、受付の非公開の置き場（Cloudflare KV）にだけ置きます
- 通報の記録（識別子と、書いてもらった詳しい内容）は、管理人が片付けたとき、または**最長1年**で消えます
- 詳しい内容の欄には、個人情報を書かないでください

## 管理人の片付け方

管理ページの「作品」で、通報の数とコメントを見られます。確かめ終わったら「通報を片付ける」で記録を消します。くわしくは [管理のしかた.md](管理のしかた.md) を見てください。
