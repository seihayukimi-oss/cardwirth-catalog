# 管理のしかた（管理人・副管理人向け）

- 管理ページ：https://seihayukimi-oss.github.io/cardwirth-catalog/admin/
- 管理人キーで入ります。キーは、パスワード管理ソフトなど、ほかの人に見られない場所に控えてください。**チャットやリポジトリには貼りません**

## 管理人と副管理人

| | できること |
|---|---|
| 管理人（1人） | すべて。副管理人の追加・外す・キーの作り直しは管理人だけ |
| 副管理人（20人まで） | 副管理人の追加・外すこと以外は、管理人と同じ。自分のキーの作り直しもできる |

- 管理人のキーは、管理ページの「はじめての設定」で作ります。Cloudflare には、キーそのものではなく**指紋**（`ADMIN_OWNER_HASH`）だけを入れます
- キーをなくしたとき・人に見られたかもしれないときは、「はじめての設定」で作り直して `ADMIN_OWNER_HASH` を入れ替えます（前のキーはすぐ使えなくなります）
- 副管理人のキーは、追加したときに一度だけ出ます。本人に、ほかの人に見られない方法で渡します

## 作品の状態

| 状態 | 意味 | カタログ |
|---|---|---|
| `public` 公開 | ふつうに載っている | 出る |
| `pending` 承認待ち | 配布ページなどで作品名・作者名が見つからなかった登録 | 出ない |
| `held` 一時保留中 | 通報が集まった・管理人が確かめている | 出る（CWカタログでは、いつもは表示しない） |
| `private` 非公開 | 掲載停止の申請・管理人が止めた | 出ない |
| `removed` 登録解除 | 編集キーで解除された | 出ない |

管理ページの「作品」で切り替えます。数分でカタログ（index.json）に反映されます。
「作品」での操作（状態の切り替え・ラベルの保存・ブロック・通報の片付け）の結果は、作品名と作品IDつきで、作品の一覧の上に出ます。ページを読み込み直すまで残ります（うまくいかなかったときは赤い字で出ます）。
GitHub の画面で `entries/` のファイルの `state` を直しても変えられます。

## ふだんの仕事

- **承認待ち**：配布ページ・作者さんのサイトなどで、作品名・作者名・代理の許可を確かめて、公開にします
- **掲載停止の申請**：申請と同時に非公開になっています。作者さんご本人からの申請かを確かめます
- **通報**：「作品」で通報の数とコメントを見ます。確かめ終わったら「通報を片付ける」。決まりは [通報の決まり.md](通報の決まり.md)
- **シナリオラベル**：対象年齢・注意のラベルの直し

## そのほかの画面

- **ラベル**：注意ラベルの種類を増やす（`catalog.json` の `content_labels`）。増やしたラベルは、登録フォームと CWカタログで、アプリを更新しなくても使えます。一度作品に付けたら、ID は変えません（名前はいつでも変えられます）
- **ブロック**：受け付けない URL・サイト（ホスト名）・作者名（`blocklist.json`）。当たる作品は登録を受け付けず、すでにある作品も次の作り直しでカタログから外れます
- **自分の設定**：名前（記録と Discord の知らせに出ます。本名でなくてかまいません）、Discord の知らせ、自分のキーの作り直し
- **副管理人**：追加・外す（管理人だけ）
- **記録**：管理ページでの操作の記録（新しい順・400日で消えます）

## Discord の知らせ

管理人ごとに、送り先（Discord の Webhook の URL）と、知らせる出来事を選べます。

| 出来事 | 最初の設定 |
|---|---|
| 承認待ちの登録（自動で公開にならなかったもの） | ON |
| 掲載停止の申請・登録解除 | ON |
| 内容の変更・サイト認証 | ON |
| 自動で公開された登録 | OFF |
| 通報が集まって、一時保留になった作品 | ON |
| 通報：リンク切れ・配布先の不備 | ON |
| 通報（1件ごと。いたずらが続くと多くなります） | OFF |

Webhook の URL は、管理ページの欄にだけ入れます。チャットなどには貼りません。

## 安全の報告の知らせ（管理人だけ）

GitHub の「Private vulnerability reporting」（cw-catalog-tool で受けています）に報告が届くと、管理人の Discord に「届きました。GitHub で確認してください」とだけ知らせます（中身は GitHub の中だけ）。
設定のしかたは、管理ページの「自分の設定」→「安全の報告の知らせ」に、画面ごとに書いてあります。合言葉（`GH_WEBHOOK_SECRET`）はチャットやリポジトリには貼りません。

## 作品のファイルを消すとき

GitHub で `entries/` の作品のファイルを消すときは、**先に管理ページで「通報を片付ける」**をします。通報の記録は作品IDごとに置いてあり、同じIDが次の作品に使われるためです。
