# 作品の登録のしかた（作者さん・代理で登録する方へ）

共用カタログには、CardWirth のシナリオ・スキン・素材の**配布場所の情報**を登録します。作品のファイルそのものはアップロードしません。
登録した作品は、CWカタログ（ツール）の一覧に出て、だれでも配布ページを開いたり、更新を確かめたりできるようになります。

- 登録ページ：https://seihayukimi-oss.github.io/cardwirth-catalog/register/
- 登録内容の変更・解除：https://seihayukimi-oss.github.io/cardwirth-catalog/manage/

## 登録できる人

- **作者さんご本人**
- **作者さん以外の方（代理登録）**：Readme や作者さんのサイトなどで、代理での登録が許可されている作品だけです。登録ページで「代理での登録が許可されている作品です」にチェックを入れます

作者さんご本人も、はじめは「代理登録」として載ります。本人の登録にしたいときは、あとで「サイト認証」をします（下の「作者さんご本人の登録にする」）。

## 登録する

1. 登録ページを開き、「登録する人」を選ぶ
2. 作品のことを書く
   - **作品名・作者名**（必須）：代理登録のときも、作者名には登録する人ではなく、作者さんのお名前を書きます
   - **種類**：シナリオ／スキン（CardWirthPy）／素材（画像・音など）
   - **形式**：クラシック（1.50）／Next仕様／Py仕様（WSN）
   - **配布URL**（必須）：作者さんの配布ページ・BOOTH・アップローダーなど。配布ページ／zipなどへの直接のリンク／ファイル一覧、から選びます
   - 予備の配布URL・作者さんのサイト・紹介ページ（X・Misskey の告知など）は、あれば書きます
   - **対象年齢**（必須）：全年齢／R15／R18（成人向け）。注意のラベル（グロ・残酷描写／ホラー／性的な表現（R15相当）など）も選べます
   - **情報元・確認方法**（必須）：配布先・作者名・代理の許可などを、どこで確かめたか
   - ほかの作品を改変したものなら、もとの作品と、改変してよいと分かるもの（規約の URL・Readme の項目など）
3. 「ロボットではありません」の確認が終わったら、「登録する」を押す
4. **作品ID**（例：e00012）と**編集キー**が出ます。編集キーは**二度と表示されません**。「コピー」を押して、メモ帳などに必ず控えてください

### すぐに載る場合・あとで載る場合

受付が、配布ページ・紹介ページ・作者さんのサイトを読みに行き、**作品名と作者名の両方**が書いてあれば、すぐにカタログに載ります（数分で反映）。
見つからなかったときは「承認待ち」になり、管理人が確かめてから載せます。

R18 の作品は、CWカタログで「R18を表示する」をONにした方にだけ表示されます。作品名・紹介文に、露骨な表現は書かないでください。

## 何作品かをまとめて登録する

同じ作者さんの作品を何作品か登録するときは、[まとめて登録する](https://seihayukimi-oss.github.io/cardwirth-catalog/register/bulk/)のページが便利です（登録ページの上にもリンクがあります）。

1. **全部の作品に共通**の欄に、作者名・作者さんのサイト・紹介ページ・予備の配布URL・情報元・確認方法を、1回だけ書く
2. **作品**の欄に、作品ごとの作品名・配布URL・対象年齢（必須）と、バージョン・形式などを書く。「＋作品を足す」で欄を増やせます（一度に20作品まで）。移行先URL・注意ラベル・タグ・紹介文は「くわしく」の中にあります
3. 「登録する人」を選び、「まとめて登録する」を押す。作品を1つずつ順番に送ります。「ロボットではありません」の確認は作品ごとに自動でやり直します（確認の画面が出たときは、押してください）
4. 最後に、作品ごとの**作品ID**と**編集キー**の一覧が出ます。「全部コピー」を押して、メモ帳などに必ず控えてください。編集キーは**二度と表示されません**

- 登録できなかった作品は、理由（赤い字）と一緒に欄に残ります。直して、もう一度「まとめて登録する」を押すと、残った作品だけを送ります
- 改変版の作品は、1作品ずつの登録ページからお願いします
- 編集キーは作品ごとに別です。登録内容の変更・解除、サイト認証も、作品ごとに行います

## 登録内容を変える・登録を解除する

「登録内容の変更・解除」のページで、**作品ID**と**編集キー**を入れます。CWカタログの作品の画面の「登録内容の変更・解除」から開くと、作品IDは入った状態で開きます。

- **修正する**：「現在の登録内容を読み込む」→ 修正する →「この内容で更新する」。作品名・作者名・配布先を変えたときは、もう一度「すぐに載る場合」の確かめをします
- **配布先を引っ越したとき**：「移行先URL」に新しい URL を書くと、前の URL は自動で「旧（移転前）」になります
- **解除する**：「登録を削除する」。カタログから外れます

## 作者さんご本人の登録にする（サイト認証）

代理で登録された作品を引き継ぐときや、編集キーをなくしたときに使います。作品IDだけでできます。

1. 「確認用コードを発行」を押す（コードは `cw-catalog-verify:…` の形。7日間有効）
2. そのコードを、登録してある**配布ページ・紹介ページ・作者さんのサイト**のどれかに書く
3. 「認証を実行」を押す → コードが見つかれば、作者さんご本人の登録になり、**新しい編集キー**が出ます（前のキーは使えなくなります）
4. 確認が終わったら、ページに書いたコードは消してかまいません

## 掲載をやめてほしいとき（作者さんご本人）

「登録内容の変更・解除」のページの「掲載停止の申請」から送ってください。**編集キーがなくても、送るとすぐに非公開**になります。そのあと管理人が内容を確かめます。

作品に問題があると思ったとき（作者さん以外の方）は、[通報](通報の決まり.md)をお使いください。

## 知っておいてほしいこと

- 登録した内容は、**だれでも見られる形**で公開されます（GitHub に保存され、変更の履歴も残ります）。カタログのデータは CC0（自由に使える）です
- メールアドレスなど、公開してはいけないことは書かないでください
- 管理人が「受け付けない」と決めた配布先・作者さんの作品は、登録できません
- データの形（くわしい項目）は [データの形.md](データの形.md) にあります
