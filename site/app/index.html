CWカタログ（ツール）

CardWirth（1.50 / Next 1.60 / Py）のシナリオ・素材・スキンを一括ダウンロードし、適切なフォルダへの振り分け、ローカル環境の一覧管理、および更新チェックを行うための非営利カタログツールです。

  • アプリ版（ポータブル版・Windows）： インストール不要。任意のフォルダに配置した CWCatalog.exe を起動するだけで利用可能です。設定およびデータは同階層の CWCatalog-data フォルダに保存されるため、アンインストールはフォルダごと削除するだけで完了します。作者様のWebサイトからの直接ダウンロード（同意ページ・DLキー・Google ドライブ対応）、配布ページの更新チェック、および CardWirth 本体の起動に対応。「設定 ＞ アプリの更新」から署名検証を伴う自動更新が可能です。
  • HTML版： cw-catalog.html をお使いのWebブラウザ（Google Chrome / Microsoft Edge）で開くだけで利用可能です（※インストール不要）。WebCardWirth用ZIPアーカイブの出力にも対応しています。

※使い方の詳細は、配布物に同梱されている はじめに.txt にも記載されています。
※アプリ版・HTML版ともに画面構造および基本機能は共通です。

📥 入手方法（ダウンロード）

アプリ版（Windows）

  1. 最新のリリース を開きます。
  2. ページ下部の「Assets」（ファイル一覧）より、CWCatalog-v○.○.○-portable.zip をダウンロードします。
  3. 任意のフォルダへ解凍（展開）し、内部の CWCatalog.exe を起動してください（※インストール作業は不要です）。
  • 旧バージョンをお使いの方は、アプリ内の「設定 ＞ アプリの更新 ＞ 更新を確認」から最新版へ更新いただけます。
  • 同じ「Assets」一覧にある CWCatalog.exe および latest-portable.json は自動更新用の処理ファイルです。初回導入時は必ず .zip ファイルをご選択ください。
  • 起動時に Windows の保護画面（警告）が表示された場合は、後述の「起動時に警告・ブロック画面が表示された場合」をご確認ください。

HTML版（Google Chrome / Microsoft Edge）

  • 公開ページ をブラウザで開くだけですぐにご利用いただけます（※常に最新状態が反映されます）。
  • ローカル環境に保存して利用したい場合は、最新のリリース の「Assets」より cw-catalog-v○.○.○.html をダウンロードしてブラウザで開いてください（※アプリ版の .zip にも同梱されています）。

🏷️ シナリオラベル（年齢区分・コンテンツ注意標記）

  • 各作品に対し、対象年齢（rating：全年齢 / R15 / R18）および注意ラベル（content：残酷描写・ホラー・性的表現等）を設定可能です。（※共用カタログの content_labels は管理側で拡張可能です）
  • R18設定作品は初期状態で非表示となっています。有効化する場合は、設定画面にて1回のみ年齢確認モーダルが表示されます。
  • R18作品のダウンロードはアプリ内では行われず、外部の標準ブラウザで配布元ページを開く仕様となっています。画像・詳細説明もユーザーが明示的にクリックした場合のみ表示されます。
  • 特定ラベルを持つ作品の非表示フィルタリングは、ラベル種類ごとに個別設定が可能です。
  • 共用カタログデータにおいて、R18作品のデータは index-r18.json へ分離されており、機能をONにしたユーザーのみが取得する安全設計となっています。

🛡️ セキュリティ・プライバシー設計

  • アクセス範囲の制限： 本アプリが書き込みを行う対象は、ユーザーが指定したエンジンの Scenario フォルダ、CWCatalog_backup フォルダ、および明示的に指定されたアーカイブ保存先のみです。宿データ（Yado）へのアクセス・変更は一切行いません。
  • 実行ファイルの保護： アーカイブ内のプログラムファイル（.exe等）を自動実行することは絶対にありません。
  • 安全なページ解析： URLおよびWebページの解析はアプリ内部（Rust）で直接処理します。ページのスクリプト（JavaScript）は実行せず、テキスト構造・ダウンロードURL・同意ボタンのみを安全に抽出します。セッションCookieはメモリ上でのみ保持し、ディスクへの永続保存は行いません。
  • メモリ上での安全検証： ダウンロードデータはディスクへ書き込まず、メモリ上でのみ安全検証を行います（※アプリ版）。ユーザーが「インストール」を確定したファイルのみをディスクへ展開します。
  • セキュリティソフトとの連携： 本アプリはウイルス対策ソフトではありません。展開されたファイルはOS標準の Windows Defender 等の監視対象となります。なお、非暗号化通信（http://）へのアクセス時は警告を表示します。
  • 不正実行ファイルの検知・除外： シナリオ以外の実行ファイル（.exe .bat .cmd .vbs .ps1 .scr .lnk 等。※拡張子が変更されている場合もヘッダーバイナリ識別印 MZ 等で自動判定）が含まれていた場合、「⚠ 注意！カードワースのシナリオ以外の実行ファイルが含まれています」と警告を表示し、デフォルトで対象ファイルを除外して展開します。
  • 構造・整合性の検証： 相対パスによるディレクトリトラバーサル（../ 等の不正パス）、異常なファイルサイズ・圧縮率、および破損ファイル（CRC不一致）の展開を事前にブロックします。
  • 文字コード・スクリプト安全化： ReadmeやカタログテキストはHTMLとして解釈せず、プレーンテキストとして安全にレンダリングします。
  • 通信の最小化： ユーザーの明示的なボタン操作時を除き、無断で外部通信を行うことはありません。
  • サンドボックス構造： アプリ内ブラウザのウィンドウは独立した外部ページとして動作し、アプリ本体のファイル操作権限や内部機能へは一切アクセスできません。
  • HTML版の安全壁（CSP）： HTML版はコンテンツセキュリティポリシー（CSP）に基づき、埋め込み済みの正規スクリプト以外の実行を遮断します。
  • 最小権限原則（Tauri）： アプリ版はユーザーがダイアログで指定したフォルダにのみアクセス権限を持ちます（CWCatalog-data に設定を記憶）。
  • 自動更新の改ざん防止： アプリの更新データは GitHub Release からのみ取得し、アプリ内に埋め込まれた公開鍵を用いてデジタル署名を検証した上で適用します。

⚠️ 起動時に警告・ブロック画面が表示された場合（Windows）

「Windows によって PC が保護されました」（青い画面）

「詳細情報」をクリック ➔ 「実行」を選択することで起動できます。

「このアプリは保護のためにブロックされました」（赤い画面）

  1. CWCatalog.exe を右クリック ➔ 「プロパティ」を開きます。
  2. 「全般」タブ下部の「セキュリティ: ブロックの解除」にチェックを入れ、「OK」を押します。
  3. 再度 CWCatalog.exe を起動してください。

Smart App Control（スマート アプリ コントロール）によりブロックされる場合（Windows 11）

コード署名準備段階の現在、Windows 11 の「スマート アプリ コントロール」が有効な環境では起動が制限される場合があります。

  • 推奨される回避策： インストール不要の「HTML版」（cw-catalog.html を Chrome / Edge で開く）をご利用ください。実行ファイル（.exe）ではないためブロックされずに快適にご利用いただけます。
  • 設定を変更する場合： 「Windows セキュリティ」➔「アプリとブラウザーコントロール」➔「スマート アプリ コントロールの設定」➔「オフ」
    (※注意：スマート アプリ コントロールを一度オフにすると、OSの再インストールを行うまで再度オンに戻せない仕様となっています。設定変更時は十分にご注意ください。なお、オフにした場合でも標準のウイルス対策機能である Microsoft Defender は正常に動作します)
