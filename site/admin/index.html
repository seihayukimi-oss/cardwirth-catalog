はじめての設定

管理人（いちばん上の人）のキーを作ります。キーはこのブラウザの中だけで作られ、どこにも送られません。

管理人キー
指紋
  1. 管理人キーを、ほかの人に見られない場所（パスワード管理ソフトなど）に控えてください。チャットやリポジトリには貼らないでください。このページを閉じると、二度と表示されません。
  2. Cloudflare の画面で、Workers →「cardwirth-catalog」→ Settings →「Runtime variables and secrets」→「Add variable」を開きます。
  3. Type は Secret、名前は ADMIN_OWNER_HASH、値に指紋（上の2つ目）を入れて、保存（Deploy）します。
  4. 30秒ほど待ってから、上の欄に管理人キーを入れて「入る」を押します。

キーをなくしたときや、作り直したいときも、ここで新しいキーを作って ADMIN_OWNER_HASH を入れ替えれば、前のキーは使えなくなります。

公開・非公開などの変更は、数分でカタログ（index.json）に反映されます。

作品に付ける注意ラベルの種類です。増やしたラベルは、登録フォームと CWカタログ（アプリを更新しなくても）で使えるようになります。

  • ID は英小文字・数字・_・-（30文字まで）。一度作品に付けたら、ID は変えないでください（名前はいつでも変えられます）
  • 「最初から」のラベルは消せません（名前と説明だけ変えられます）
